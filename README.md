 1. Project Overview

EventHub is a mobile-first event booking application designed to solve the problem of scattered, informal event discovery (via social media and word of mouth) by giving users one trusted place to browse events by category, view details and reviews, book tickets, and pay securely via Mobile Money or Card.

The design includes 8 fully connected screens — Login/Register, Home/Event Listing, Event Details, Ticket Selection, Checkout/Payment, Booking Confirmation, My Tickets, and Profile — built as a clickable, interactive prototype with both light/dark theme support and a wireframe/hi-fi view toggle.

 3. Design Decisions and Features

Design decisions:
- Chose a bottom-up user flow (Login → Browse → Details → Ticket → Pay → Confirm) to keep the path to purchase as short as possible.
- Used a consistent visual system — indigo primary color, amber accent, rounded cards and pill buttons — to keep the app feeling modern and trustworthy.
- Built a dark mode variant to improve usability in low-light conditions and demonstrate design system flexibility.
- Included a live wireframe/hi-fi toggle so structure and visual polish could each be reviewed independently.

Key features implemented
- User authentication (Login/Register)
- Event discovery by category (Concerts, Conferences, Workshops, Summits)
- Event details with location, organizer info, and reviews
- Ticket quantity selection with live price calculation
- Checkout with Mobile Money and Card payment options
- Booking confirmation with "Add to Calendar"
- My Tickets (Upcoming/Past) history
- User profile
- Light/dark mode toggle
- Accessible color contrast, readable typography, and consistent navigation across all screens
